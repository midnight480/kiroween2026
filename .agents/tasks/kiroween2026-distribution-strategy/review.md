Point 1 は §8 新サブ「配布方式（MVP）✅ 方針決定」の冒頭で、`トランスパイラ本体は TypeScript/Node 実装（§6）なので、COBOL ランタイムを同梱せずに macOS / Windows / Linux で動く` と明言し、続けて `MVP の配布は npm / npx` を打ち出す。CLI 例 `npx cdk-cobol compile deploy.cbl` は括弧内で `CLI は §4.6 の cdk-cobol compile <file.cbl> と同じ` と自己照合しており、§4.6 のコードブロック（163 行目 `cdk-cobol compile <file.cbl>`）と綴りが一致する。コマンド名が実在の CLI 名 `cdk-cobol` である点、タスク要件どおり。
